# MATCHDAY 99 v0.9.1 — oyuncu dokusu düzeltmesi

[**Düzeltilmiş yama paketini indir**](https://github.com/necaticturk-rwf/matchday99/raw/refs/heads/matchday99-v09-downloads/teslim/v0.9.1/MATCHDAY99_v09_1_YAMA.zip)

Önceki v0.9 yaması, bayraklarla oyuncu dokularının grafik belleğinde çakışmasına yol açıyordu. v0.9.1 bu hatayı düzeltir. Orijinal v0.8 veya bozuk v0.9 dosyalarından ayrı, doğrulanmış BIN/CUE oluşturur; kaynaklara yazmaz.

ZIP'i çıkarın, [BASLA.txt](BASLA.txt) adımlarını uygulayın. Python 3 yeterlidir. Yeni `ISS Pro Evolution - MATCHDAY99_v09_1.cue` dosyasını baştan açın; eski emülatör save state'ini yüklemeyin.

20 kulübün seçim, büyük bayrak ve skorbord pikselleri gerçek emülatör VRAM'inde doğrulandı. İki takımın fotoğrafları ve maçın başlaması kontrol edildi. Maç içi yüz/vücut/forma dokuları ve bayrak dışındaki paletler v0.8 ile birebir aynı. 240 ISO dosyası ve v0.8'in mevcut 4.900 değişiklik baytı korunmuştur. PCSX-ReARMed ile test edildi; ePSXe bu ortamda test edilmedi.
